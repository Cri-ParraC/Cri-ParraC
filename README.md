## Hi, I'm Cristian

I'm a full stack developer based in Santiago, Chile. I work with TypeScript, JavaScript, Angular and Node.js.

I like to really understand what I'm doing, so I read a lot of theory. I like to write code that is just simple enough because I respect the readers (coworkers and my future self) and their time. Less is more!
